Cours

Une arborescence, c’est quoi ?

Une arborescence est une organisation hiérarchique de dossiers et de fichiers. Elle fonctionne comme un arbre : un dossier principal contient des branches, puis des sous-branches.

Durée conseillée : 8 à 10 min

1. Les 4 notions à connaître

🗂️

Dossier racine

C’est le dossier principal. Dans notre cas : Outdoor_Jadore.

📁

Dossier / sous-dossier

Un dossier peut contenir d’autres dossiers. Exemple : 01_CLIENTS › FACTURES.

📄

Fichier

Un fichier est un document : PDF, Word, Excel, image, courriel exporté, etc.

🧭

Chemin d’accès

Il indique précisément où se trouve un fichier dans l’arborescence.

💡
Le bon réflexe : se demander d’abord « à quelle grande famille appartient ce document ? », puis « quel sous-dossier décrit le mieux sa nature ? ».

3. Les règles de classement numérique

  • Un emplacement logique et unique : éviter de dupliquer le même document partout.
  • Des noms de dossiers simples : CLIENTS, FOURNISSEURS, RH, COMMUNICATION…
  • Une structure stable : toute l’équipe doit utiliser la même logique.
  • Des droits d’accès adaptés : un contrat de travail ne doit pas être rangé avec les photos de communication.
  • Des archives séparées : les documents anciens restent retrouvables sans encombrer les dossiers actifs.
À retenir : classer, ce n’est pas seulement « ranger ». C’est permettre à une autre personne de retrouver rapidement le bon document, au bon endroit.

4. Reconnaître rapidement les fichiers

📄 PDF = document figé 📝 DOCX = document Word 📊 XLSX = tableau Excel 🖼️ JPG/PNG = image ✉️ MSG/EML = courriel 📁 Dossier = ensemble de fichiers
